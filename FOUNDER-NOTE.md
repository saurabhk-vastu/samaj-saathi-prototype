# Samaj Saathi prototype note for the founder

This is a clickable, high-fidelity mobile prototype of Samaj Saathi. It is meant for review on a phone or inside the on-screen phone frame on desktop.

## What changed, and what did not

I focused almost entirely on UI and UX. The product flow, screen purpose, and core features stay the same as the live app. Users still create a biodata, set preferences, browse matches, like profiles, open chats, manage their profile, and see recharge and help screens.

I did not invent a new product. I did not remove major features or redesign the journey from scratch. Where something looks different, it is usually clearer layout, calmer visuals, better spacing, and more consistent interaction patterns.

## Why this prototype exists

The current product works, but the experience can feel crowded and hard to scan. This prototype shows how the same features can feel clearer and more trustworthy, while keeping language and steps familiar for Indian family users.

## What you can try

- Language selection, mobile OTP (use any valid Indian number, OTP is **1234**)
- Full biodata onboarding and match preferences
- Home with matches across major states, shortlist, and filters
- Profile view with call, WhatsApp, message, report, and help
- Likes, messages, and account settings (privacy, subscriptions, language, logout)
- Recharge opens the ₹1 trial screen. In this prototype there is no real payment, so the home recharge banner stays visible on purpose.

## Demo link

https://samaj-saathi-prototype.vercel.app

## How to read this demo

Please judge the clarity of each screen, the ease of moving through the flow, and whether the app still feels like Samaj Saathi. Feature gaps versus the live app are intentional only where a real backend, SMS, or payment would be needed.

If something feels off against the live product, call it out. The goal is a better looking and easier to use version of the same product, not a different one.
